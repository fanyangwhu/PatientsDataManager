共享访问

同一科室的其他电脑，在浏览器里打开 http://{{ request.host }} 即可共用这套系统（需在同一局域网，且本程序保持运行）。

使用要点

  1. 先在「字段管理」里配置你需要的字段（文本 / 数字 / 日期 / 单选 / 多选 / 是否），字段可随时增删。
  2. 录入方式：手动新建，或用「Excel 导入」——先下载模板，填好后上传，系统会自动匹配列名并校验。
  3. 列表页支持按任意字段筛选、关键词搜索、排序，结果可直接导出 Excel。
  4. 所有增删改、导入导出均记录操作人与时间，管理员可在「审计日志」中查证；删除的记录会保存快照。
  5. 标记为「敏感」的字段（如姓名、电话）在列表中默认脱敏显示，仅管理员在详情页可见完整值。
